# 06 · 打包与分发方案

> 目标一句话：**产出一个 exe，拷到任何 Windows 目录双击就能用**。参照 Tool_ProcessPortManger 已验证的 PyInstaller 路线。

## 1. 构建脚本草案（build_windows.bat）

```bat
@echo off
chcp 65001 >nul
rem ============================================
rem  项目启动精灵 · Windows 单文件打包脚本
rem  产物: dist\项目启动精灵.exe （约 10~15MB）
rem ============================================

pip install -r requirements.txt
pip install pyinstaller

pyinstaller ^
  --onefile ^
  --noconsole ^
  --name 项目启动精灵 ^
  --icon assets\spirit.ico ^
  main.py

echo.
echo 打包完成: dist\项目启动精灵.exe
echo 首次运行会在 exe 旁边生成 profiles.json / logs\
pause
```

**bat 编码铁律（2026-09-23 实测教训，缺一即碎行）**：`build_windows.bat` 必须保存为 **UTF-8 无 BOM + CRLF 行尾**，且 `chcp 65001` 必须先于文件中任何中文字符执行。三要素被破坏任一（编辑器存成 LF、存成 GBK、加 BOM、中文出现在 chcp 之前），cmd 都会按错误码页/行尾解析，产生"中文命令被拦腰截断、`^` 续行吞字符"的碎行报错。

## 2. PyInstaller 要点

| 项 | 处理 |
|---|---|
| `--onefile` vs `--onedir` | onefile：单文件拷走即用，但首次启动要解包到临时目录，白等 2~5 秒；onedir：秒开但是一堆文件。**首选 onefile**（"拷走即用"优先），若实测等待不可接受再降级 onedir + zip 分发 |
| `--noconsole` | GUI 程序不弹黑窗；子进程输出全部走日志捕获（docs/03 §3.4），不依赖父控制台 |
| psutil | PyInstaller 一般能自动收集；若报 `No module named psutil`，加 `--hidden-import psutil`；子模块仍缺时 `--collect-all psutil` |
| 图标 | `assets/spirit.ico` 放仓库；没有图标就删掉 `--icon` 行，v0 不为图标阻塞 |
| exe 路径锚定 | 代码里一律 `Path(sys.executable).parent` 定位配置（docs/05 §1.2）；PyInstaller onefile 下 `__file__` 指向临时解包目录，**不可用** |
| 杀软误报 | PyInstaller 单文件偶发 Defender 误报；先加白名单；仍不行换 `--onedir` 或对 exe 签名（个人工具优先接受加白） |

## 3. 版本与命名

- 产物命名：`项目启动精灵.exe`（中文命名与工作区习惯一致）。
- 版本号写在 `main.py` 常量 + 状态栏显示（docs/04 §1），v0.0.1 起。
- rar 快照惯例：每完成一个版本，打 `Tool_ProjecStartupSpirit YYYYMMDD.rar` 留档。

## 4. "拷走即可用"验收清单

打包后逐项过一遍（对应 docs/01 §5 第 6 条验收）：

| # | 场景 | 预期 |
|---|---|---|
| 1 | 本机干净目录：只拷 exe 到新文件夹，双击 | 能起、自动扫描、列表出现 28 项目 |
| 2 | 连同 `profiles.json` 一起拷 | 收藏/覆盖/设置全部还在 |
| 3 | **无 Python 的机器**（或临时改 PATH 隐藏 python）双击 | 照常运行（exe 自带运行时） |
| 4 | 运行后检查注册表与 `%APPDATA%` | 无新增项（便携铁律） |
| 5 | 启动一个 embedded 型（PWA）项目 | 内置 http 服务正常、浏览器能开、防火墙**不弹窗**（绑定 127.0.0.1） |
| 6 | 启动一个 service 型（node）后关闭精灵主窗口 | 按"让它们跑"退出后服务仍在；重开精灵能重新认领 |
| 7 | exe 被占用时再次打包 | 构建脚本报错提示先关程序（加 tasklist 检查） |
| 8 | U 盘 / 中文路径 / 带空格路径下运行 | 全部正常（路径统一 `pathlib` + 引号） |

## 5. 分发形态

v0 只在本机使用，不做安装器、不做自更新。分发 = 拷文件夹。日后要给别的机器：zip 整个目录（exe + profiles.json 可选）即可。
